# Automatic Traffic Light System Using Arduino Uno

## Project Overview
This project simulates an automatic traffic light system using Arduino Uno in Tinkercad.

## Components Used
- Arduino Uno
- Red LED
- Yellow LED
- Green LED
- Resistors
- Breadboard and connecting wires

## Working
The Arduino program controls the traffic light LEDs in sequence. The red LED indicates STOP, the yellow LED indicates WAIT, and the green LED indicates GO.
